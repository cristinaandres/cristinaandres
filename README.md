## 🎯 My Approach: Design + Data

I don't just analyze data; I design how it is presented.

- **Empathetic questions:** Before writing a query, I ask myself who will read the result and what decision they will make with it.
- **Self-explanatory dashboards:** I apply principles of visual hierarchy, color, and typography so charts don't need an instruction manual.
- **Data storytelling:** An analysis doesn't end in a notebook; it ends in a clear, visual recommendation.
